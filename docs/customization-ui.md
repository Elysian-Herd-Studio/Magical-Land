# 捏马指南

从游戏主菜单右下角的“捏马”进入编辑器。F9 或 Mod Menu 中的 Magical Land 入口打开设置／关于页面；主菜单按钮的显示方式可在“设置 → 通用”中调整。

编辑器采用全宽布局：

- 顶部分类：身体、鬃毛、面部、角与翅、魔法、可爱标志。
- 左侧：角色预览、预设切换与管理、自动聚焦开关。
- 右侧：当前分类的独立滚动细项，各分类分别记住滚动位置。
- 鬃毛分为前发、后发和尾巴子栏，各自显示款式缩略图与颜色选项。眼型也通过缩略图选择。
- 拖动预览旋转角色；右键或重置按钮恢复当前聚焦角度，关闭自动聚焦后恢复全身视角。手动模式且空间足够时显示视角方块。
- 魔法分类可切换小马与悬浮物品的光效预览。小马预览会播放待机、眨眼、抽耳朵和尾巴动画。

预览使用固定照明：主光来自镜头左上后方 45 度，另有正面补光。它只影响预览的显示，魔法光晕保持发光。

在世界中使用 Gameplay 时，当前玩家的主预览遵循服务器的角翅显示规则；编辑器仍保存原有外观选择，临时显示覆盖不会写回草稿或预设。是否允许外观混搭由 Gameplay 设置控制。标题界面没有当前玩家时及款式示例缩略图，仍显示原外观。

## 预设

“小马管理”界面的“云预设”提供在线保存、导入与公开展示，使用方式见[云预设](cloud-presets.md)。

点击预览上方的名称打开预设下拉菜单，其中标记当前选择和未保存草稿。右侧“＋”输入名字后新建，“−”显示完整名称并二次确认删除，至少保留一个预设。确认或取消后返回原编辑分类；点击菜单外部只收起菜单。

菜单底部的“管理预设…”提供新建、复制、改名和删除。副本保留原预设的颜色、锁定和挑染设置，可以独立修改。

重命名时按 Enter 确认、Esc 取消；名称不能与其他预设重复。名称输入完成前，暂时不能编辑款式或保存应用。确认名称后，仍需点击“保存并应用”才会保存。

切换预设保留各自草稿和绘图历史，退出编辑后释放。新建、删除和改名先记入草稿，点击“保存并应用”后才写入文件；放弃编辑可撤销这些操作。

## 颜色

颜色选项包括自动或手动设置高光与阴影、颜色锁定、六区挑染、虹膜渐变和高级眼色。按 Esc 或点击色板外部可关闭色板，不会选中后方的款式。

## 缩略图与镜头

款式缩略图由当前资源包的模型生成，以固定配色的素体试穿目标部件。缩略图保持示例颜色，左侧主预览实时显示草稿配色与挑染。缩略图实时调色见[待办清单](../TODO.md)。

缩略图带深度并保持原比例，仅生成可见卡片，离开或资源重载时释放。创建、淘汰与清空缓存后，必须恢复此前的渲染目标和状态，尤其不能误切到 framebuffer 0；预览使用独立骨骼，不改写玩家配置。

选择前发或眼型聚焦头部，后发转到头后侧，尾巴转到臀部斜后方。根据真实部件和必要素体的包围盒拟合距离，平移、旋转与缩放按经过时间平滑过渡，不跟随鼠标悬停跳转。静止视角保留边距容纳待机运动；过渡途中允许短暂经过原来的裁切位置，完成后完整显示目标部件。

方向键浏览款式卡片，Enter／空格确认，当前款式与键盘焦点分别标示。右栏按条目实际高度处理滚动和点击。

## 保存保护

外观与预设操作先保存在内存草稿中，编辑期间其他玩家看不到变化。`getActiveModel()` 用于界面草稿，世界渲染、手持物和网络发送使用 `getAppliedModel()`。Magical Land 设置页中的全局开关独立保存。

点击“保存并应用”后，才会保存本次所有预设操作，更新角色外观并同步给其他玩家。关闭界面时若有未保存内容，会询问是否丢弃；丢弃、异常离开或断线后恢复上次已应用的外观。

保存并退出时，角色周围会散开变身光尘（28 个光点和 4 个微星，约 0.8 秒，无声音）。仅修改名称、外观未变化或接收初始同步时不播放。

服务器在 100 ms 限流期间保留每名玩家最后一份合法外观，到期后应用；关闭广播、断线或停服时清理等待项。光尘遵循粒子设置、冷却、隐身与遮挡规则；普通模式只写颜色，Fabulous 模式另写独立粒子目标的深度供透明合成。

JSON 使用 UTF-8。提交前核对外部文件变化，预写临时文件并保留回滚备份；失败不应用或广播，草稿仍在。损坏 JSON 不加入编辑列表，也不会被覆盖或误删。若故障导致回滚也无法完成，保留 `.appearance-edit-*` 恢复文件并在日志给出路径。

常规写入失败时会尝试回滚，并保留草稿；如果写入过程中断电，多个预设文件仍可能只保存了一部分。

- `CustomizationLayoutTest`：320×240 至 1920×1080 的布局、控件和旋转区域边界，共 328233 次检查。
- `PreviewCameraTest`：715409 项完整入镜、窗口尺寸、平滑过渡、最短角度和立即复位检查。
- `StyleGridLayoutTest`：自适应列数、命中间隙、可见卡片、键盘和资源编号检查。
- `PreviewGeometryBoundsTest`：真实模型、私有状态、配件范围及固定缩略图配色检查。
- 缩略图宽高比和离屏渲染状态回归覆盖缓存淘汰、清空及嵌套 framebuffer。
- `TransformationBurstMathTest`：41748 项数量、亮度、寿命、轮廓分布和身体朝向检查。
- 预设兼容与草稿事务检查必须使用隔离的 Fabric／配置／网络 stub 和临时目录，不能对玩家真实配置目录运行。
- 中英文文案完整性检查。
