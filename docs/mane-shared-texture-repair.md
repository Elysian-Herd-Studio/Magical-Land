# 鬃毛纹理与 UV

全部现有款式共用一张 256×256 图集，模型逻辑 UV 为 128×128。22 个部件的 UV 分别集中排列，每个方块的六面组成一组展开图，便于手绘和定位。

当前 297 个毛发方块、1782 个面均使用表面分区，每个现有部件各有六区。模型形状、骨骼和动画保持原样，后发 07、尾巴 08 留空。

## 资源对应

- 灰度贴图：`Resources/Textures/MareMane.png` 与运行时 `textures/entity/mane.png`。
- 模型：`Resources/Models/Mare.geo.json`、运行时 `geo/mare_geo.json` 与 `Resources/BlockbenchProjects/Mare.bbmodel`，三者 UV 同步。
- 表面分区：`Resources/ManeDyes/surfaces.json` 与运行时 `mane_dyes/surfaces.json`。
- 兼容像素遮罩：运行时 `mane_dyes/stripe01.json`、`style02.json` 至 `style08.json`。
- 合并预览：`Resources/Textures/BaseTextureBackup.png` 与工程内嵌副本；游戏分别读取身体与鬃毛贴图。

Blockbench 工程内的鬃毛贴图按款式分为八层，另有一层保留区域，合成后与运行时贴图一致。每个方块各面独立分配像素，支持不同方向的独立分色。

图集采用紧邻排列，空白处延展相邻颜色。当前渲染使用最近邻采样并关闭 mipmap；线性过滤或着色器可能改变边缘表现。

## 编辑分区

当前色区以 `surfaces.json` 为准：按模型面记录连续分色边界，用原 UV 取灰度纹理。分区可以按整束、整块或连续宽带安排；共用纹理的不同面仍可独立分色。01 前发六带等宽，后发按三层分支各分两色；03 尾巴沿整块归色，08 前发按六组完整毛束归色。

更改 UV 或方块顺序时，同步更新分区、源模型、运行时模型和工程内嵌图片，并检查覆盖范围及相邻面的接缝。灰度纹理继续使用 256×256 图集，分色边界的精度独立于纹理像素。

本地总遮罩 PNG 和逐款 Blockbench 遮罩工程保留为旧像素方案的编辑资料。`flow-layout.json` 保存 2026-09-09 的发流参数，供历史方案参考。

分色格式见[遮罩分色](mane-mask-dye.md)，运行时镜像见[左右镜像](mane-mirroring.md)。

### 纤维素材来源

灰度纤维源由 imagegen 生成，降采样后按表面朝向、发流和三阶色调装入图集。素材采用 32×32 粗像素风格，纵向不规则发丝、少量 1 像素断笔，主灰度为 225–250/255，沟纹为 200–220。整体亮度较均匀，局部光影由模型对应区域补充。
