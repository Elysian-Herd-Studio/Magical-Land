# 云预设

在“小马管理”界面点击“云预设”。未登录时显示全屏登录引导，点击“登录”在浏览器完成授权后进入自己的云预设列表，也可以点击“共享预设”直接浏览公开内容。

点击“账户信息”查看当前账户的头像和名称。点击“编辑用户信息”打开 MGL Skin 网站的个人资料页面，修改后返回游戏点击“刷新”更新显示。未设置头像时显示名称首字母。在账户信息页点击“退出登录”后需要再次确认，确认后回到登录引导，取消则返回账户信息页。

云预设列表按更新时间分页显示，并标注每项的公开状态。选择预设后，点击“预览与导入”查看外观并保存到本地。

点击“上传预设”选择本地预设。新预设默认仅自己可见；同一账号上传同名预设会覆盖云端内容，并保留该预设的公开设置。

选择云预设后，点击“公开展示”让其他人在模组的“共享预设”和网站皮肤库中浏览、导入。点击“设为不公开”后，在线列表和详情仅对所属账号开放。其他人此前已导入的本地副本仍会保留。

“共享预设”可直接浏览公开内容。云预设与本地预设分别保存，导入时需要使用尚未占用的本地名称。在线服务地址可在设置的网络页面修改。

客户端需要配套更新后的 MGL Skin 服务端。服务端首次更新数据库时，为已有预设补充可见性字段，默认设为不公开；用户可以在云预设或网站“我的皮肤”中重新开启公开展示。
